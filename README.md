# 👋 ¡Hola! Soy Laura Cabrera

Soy **Desarrolladora de Software Junior** con formación técnica en Programación de Software, **Tecnóloga en Análisis y Desarrollo de Software** y estudiante de **Ingeniería de Sistemas**.

Me apasiona crear **soluciones digitales robustas, funcionales y escalables**, con especial interés en el **desarrollo backend** utilizando **Java con Spring Boot** y **Python con Django**, complementando con **frontend moderno** en **Angular**, **JavaScript** y **TailwindCSS**.
